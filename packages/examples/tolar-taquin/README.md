# Tolar Taquin Vue Example

This example demonstrates how to connect a Vue frontend to the Taquin wallet.
## Overview

The project consists of:

 **Tolar Web3 Plugin Example (this project)** – a Vue frontend that interacts with the wallet

The wallet must be running in the browser for this example to work.

---

## Prerequisites

- Node.js = 20.17.0
- Yarn
- Taquin wallet built and installed in the browser  
  Repository: https://github.com/Tolar-HashNET/tolar-enKrypt (branch: `tolar-master`)

---

## Running the Example

```bash
yarn install
yarn dev

The app will be available at: 
http://localhost:8080
