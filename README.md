# Web3.js Tolar Hashnet Plugin
Tolar web3 plugin workspace containing plugin and usage examples.

## Workspace projects
- [Plugin implementation](./packages/plugin)
- [Blockchain example](./packages/examples/blockchain)
- [Send signed transaction example](./packages/examples/send-signed-transaction)
- [Smart contract example](./packages/examples/smart-contract)
- [Wallet send transaction example](./packages/examples/wallet-send-transaction)
- [Tolar Taquin Vue Example](./packages/examples/tolar-taquin)

## Prerequisites
- [NodeJS](https://nodejs.org/) (LTS/Iron)
- [yarn](https://yarnpkg.com/getting-started/install)
- [web3js 4.0 or higher](https://www.npmjs.com/package/web3)

## Build All
```bash
# Install
yarn install
# Just build plugin
yarn build
# Build
yarn build:all
# Test plugin
yarn test
```
